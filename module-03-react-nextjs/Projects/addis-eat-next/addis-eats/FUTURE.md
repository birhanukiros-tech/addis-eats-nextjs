# Future Improvements — Addis Eats

## Features Deferred

The capstone prioritised the main food-ordering experience, authentication, protected routes, data handling, performance, and deployment.

The following improvements could be added in future:

- **Payments:** Integrate a secure payment provider.
- **Notifications:** Notify customers when an order status changes.
- **Order management:** Improve order history, tracking, and cancellation workflows.
- **Testing:** Add automated unit, integration, and end-to-end tests.
- **Accessibility:** Conduct a complete keyboard and screen-reader review.
- **Performance:** Continue measuring Core Web Vitals and optimise based on evidence.
- **Deployment:** Add automated checks and monitoring for production errors.

## Next Steps

Prioritise automated tests and security verification, then improve order notifications and payment integration.

These items are future plans, not claims that the features already exist.
